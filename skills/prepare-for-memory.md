# Prepare for Memory

> **EMPIRA component**
> Component ID: `prepare-for-memory`
> Version: `1.0.0`
> Included in: `EMPIRA 0.1.0`

## Коли використовувати

Використовуй, коли користувач просить **«Підготуй для Memory»**, **«Підготуй це для Memory»** або явно хоче перенести корисний результат поточного чату в Notion Memory.

## Мета

Перетвори зміст поточного чату на компактний, самодостатній handoff для іншого AI, який матиме доступ до актуальної Memory.

## Що включати

- підтверджені факти та важливий контекст;
- актуальний стан;
- прийняті рішення й домовленості;
- суттєві зміни стану;
- важливі причинно-наслідкові зв'язки;
- відкриті питання або наступні кроки, якщо вони справді важливі для продовження роботи.

## Що не включати

- повний переказ чату;
- повтори, проміжні міркування, відкинуті варіанти без довгострокової цінності;
- непідтверджені припущення як факти;
- службові пояснення про те, як ти формував handoff.

## Важливе обмеження

Не визначай остаточно `Type`, `Domain`, `Status`, `Related`, не вирішуй, який існуючий об'єкт Memory треба змінити, і не створюй модель структури Memory. Це має вирішити AI, який прочитає актуальний Memory System Guide і побачить фактичну Memory.

## Формат результату

Видай один блок **Memory handoff**. Він має бути зрозумілим без читання попереднього чату. Групуй інформацію природно за змістом, а не за фіксованим шаблоном. Якщо щось є припущенням або ще не підтверджено — познач це прямо.

Не записуй нічого в Notion на цьому кроці, навіть якщо маєш до нього доступ, якщо користувач окремо не попросив перейти до внесення.
